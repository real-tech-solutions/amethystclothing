## 2. STRICT ANTI-AI UI RULES

> These rules are NON-NEGOTIABLE. Violation of any rule is a failed deliverable.

1. **NO** bubbly rounded corners. `border-radius: 12px` or `16px` is **FORBIDDEN**. Use `0px` (sharp rectangular edges) or maximum `2px` micro-radius for inputs/buttons.
2. **NO** cheesy purple-to-pink glowing gradients, glassmorphism blur cards, or floating pastel blobs.
3. **NO** generic Bootstrap/Tailwind-template look.
4. **NO** emojis in UI headings or buttons.
5. Use crisp `1px solid #E6E2EE` structural hairline borders, architectural grid lines, generous whitespace, and bold typographic hierarchy.
6. Design must look like it was built by an elite fashion brand's in-house team — not generated by AI.

## 5. Architecture

- **Stack:** Native PHP 8.x + MySQL (InnoDB, utf8mb4) on XAMPP
- **Pattern:** Front Controller (`index.php`) → Router → Views in layouts
- **No frameworks.** No Composer dependencies unless absolutely necessary.
- **Database:** 39 tables across 11 modules (see `amethystclothing_db.sql`)
- **Session-based auth** with CSRF protection on all forms.
- **PDO** with prepared statements — no raw `mysql_*` or `mysqli_*`.

## 7. Currency System

- **Primary currency:** LKR (Sri Lankan Rupees)
- **Secondary:** USD
- **Session-based switching** via `$_SESSION['currency']`
- All prices stored in LKR in the database; converted on display using `exchange_rate` from `currencies` table.
- `format_price($amount)` handles conversion and formatting automatically.
